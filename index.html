Local data protection

Backup and Restore

A complete backup includes cards, card images, sets, grading information, notes, and saved recognition results.

Restoring merges the backup with data already on this device. It does not delete existing cards and does not call CardSight.

Collection transfer

Import Cards from CSV

Import an existing collection list without scanning cards. Common column names such as Player, Year, Set, Manufacturer, Card Number, Sport, Value, and Notes are recognized automatically.

CSV importing never calls CardSight or AI grading. Importing the same unchanged file again skips rows that were already imported. Duplicate cards listed on separate rows remain separate cards.
